# 枪械 LOD（已移出模组）

> **状态**：引擎已从模组中整体移出，暂存于 [`todo/gun-lod/`](../../../todo/gun-lod/README.md)，
> 不再参与构建与发布。本页保留作为入口，避免其它文档的链接失效。

## 现在是什么行为

- 其他玩家手持的枪械一律渲染 TaCZ 的完整模型，不按距离替换几何。
- 不按距离停掉枪械状态机动画。
- 没有后台预热、LOD 进度条，也没有 `gun_lod` / `other_player_gun_lod` 配置项。
- 枪 id 环形记忆与手枪判定缓存仍在（副手枪 locator 需要），资源重载时清空。

## 为什么移出

引擎本身需要大改（减面策略、按持有回收、预热并发与内存上限），且"必须保持可辨识轮廓"与
"纯性能优化、允许 best-effort"这个产品判断尚未裁决。移出前既不继续承担它的性能收益，也不
继续承担它的内存与验证成本。

历史设计、实测数据与失败边界见 [`todo/gun-lod/docs/gun-lod.md`](../../../todo/gun-lod/docs/gun-lod.md)；
恢复步骤见 [`todo/gun-lod/README.md`](../../../todo/gun-lod/README.md)。
